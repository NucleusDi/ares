# Встроенный менеджер профилей ares v148

Сборка добавляет менеджер файлов настроек `*.bml` на страницу
`Settings -> Settings File`.

## Использование

1. Запустите `F:\Ares\ares-profile-manager.exe`.
2. Откройте `Settings -> Settings File`.
3. В списке `Settings Profiles (*.bml)` выберите профиль.
4. Нажмите `Activate`.

По умолчанию менеджер сканирует папку текущего файла настроек. Для установленной
сборки это `F:\Ares`, поэтому в списке появляются существующие файлы
`ares-settings-*.bml` и `settings.bml`.

Кнопка `Folder...` выбирает другую папку профилей, а `Refresh` повторно сканирует
её. Активный файл помечается суффиксом `(current)` и становится файлом, в который
ares сохраняет дальнейшие изменения.

## Комментарии

Однострочные BML-комментарии должны начинаться с `//`:

```bml
// Профиль для TCL C835 65"
// HDMI, 3840x2160, игровой режим телевизора

Video
  Driver: OpenGL 4.6
```

При автоматическом сохранении ares комментарии сохраняются и собираются в
заголовке файла. Окно `Settings File` показывает исходное содержимое активного
файла, включая комментарии.

## Дата и время состояний

В меню `Tools -> Save State` и `Tools -> Load State` занятый слот отображается
как `Slot 1 — 2026-09-21 18:42:07`. Дата берётся из времени последнего изменения
файла состояния, поэтому функция работает и с ранее созданными сохранениями.
После нового сохранения или отмены сохранения подпись обновляется сразу.

Пустые позиции подписаны `Empty` и недоступны в меню загрузки. Имена файлов
`.bs1` ... `.bs9` и их формат не изменяются, поэтому совместимость с обычным
ares сохраняется.

## Безопасность установки

Оригинальный `F:\Ares\ares.exe` не изменён. Модифицированная сборка установлена
как `F:\Ares\ares-profile-manager.exe` и использует те же каталоги Database,
Shaders, Systems и Games.
